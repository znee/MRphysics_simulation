What You're Seeing

Without gradients, all spins have the same phase (pointing same direction). Toggle gradients to see how they create position-dependent phase patterns.

\(\phi(x,y) = \gamma \cdot (G_x \cdot x + G_y \cdot y) \cdot t\)

Key Difference

Gx (Frequency): ON during readout → phase accumulates continuously → oscillating signal
Gy (Phase): ON before readout, then OFF → fixed phase imprint → constant magnitude

What you're seeing (panel guide)
  • Row ① Acquire (top) — runs during the scan, then stays frozen in its final state:
    • Voxel signals → Σ: each voxel's own signal during this readout (wiggle speed ∝ x, starting phase ∝ ky·y, height ∝ ρ). All of them flow into Σ = the coil, where noise is added.
    • Summed readout → k-space: white = real part, amber = imaginary part of the complex coil signal (the receiver's two quadrature channels); line = noiseless sum, dots = measured samples (sum + noise). Each dot is written into one k-space cell; one readout fills one ky line.
    • Pulse sequence: the Gy step sets ky; the cursor marks the sample being taken.
    • Phasor sum: voxel arrows head-to-tail; white = their sum, magenta = noise, cyan = what is measured.
  • Row ② Reconstruct (bottom) — starts when k-space is full; the cyan ring in row ① marks the k-space value being used:
    • K-space → patterns: components used so far (bright) and the stripe pattern of the current one.
    • Reconstructed image: the sum of all patterns added so far, with the true object, counter and SNR.
    • Order: Centre-out adds low k first so the image sharpens from coarse to fine; Scan order adds the lines in the order they were acquired in row ①.
    • Component weight: size + phase of the current pattern (= that k-space value).
Try this
  • Step through the first line: when the voxel arrows line up the sum is big; when they fan out they cancel.
  • Pick Single voxel: |S| is the same in every k-space cell, only the phase changes — a point contains all spatial frequencies.
  • Set noise to 0 → the background turns black. Raise it → speckle appears everywhere, even far from the object.
  • NEX 1 → 4: SNR doubles (√4) but the scan takes 4× longer.
  • Skip to decompose (centre-out): the first ~10 components give a blurry blob; the last ones sharpen the edges (and, with noise, add mostly noise).
  • Switch the order to Scan order (Letter "L"): the outer ky lines come first and show only the horizontal edges (where ρ changes along y); the vertical bar fills in once the central lines (ky ≈ 0) are added. The final image is identical.
Key points
  • The coil measures only the sum of all voxels: one sum = one k-space sample, one readout = one ky line.
  • Each k-space value is the weight (amplitude + phase) of one stripe pattern; the inverse FT adds them back.
  • The order of the additions is only for display: a sum does not depend on order, and a real scanner computes the whole inverse FT at once with an FFT after the scan. (Centric ordering in a real scan, e.g. contrast-enhanced MRA, changes the acquisition order instead, to time the k-space centre to peak contrast.)
  • Noise is added to every sample at the receiver, so after the inverse FT it spreads evenly over the whole image. Image SNR = ρ·N·√NEX/σ here (more samples → more averaging).

This demo keeps ρ = 1 per voxel when N changes. In a real scan at the same FOV, 16×16 voxels hold ¼ of the signal, so SNR drops (see Part 4).

Common misconception

"A k-space point is a pixel." No: every k-space sample contains signal from every voxel, and every pixel is built from every k-space sample.

\(\Delta z = \dfrac{BW}{\bar{\gamma}\, G_z}, \quad z_c = \dfrac{\Delta f_c}{\bar{\gamma}\, G_z}\)
What you're seeing (panel guide)
  • Panel 1 (top-left): cyan line = Larmor frequency along z with Gz on, f(z) = γ̄·Gz·z. Orange band = frequencies in the RF pulse. Where they cross is the slice (green). The arrows below are spins: only those in the slice are tipped.
  • Panel 2: the sinc RF pulse plays during the Gz lobe, followed by a negative rephaser lobe.
  • Panel 3: RF envelope in time (left) and its Fourier transform = the slice profile (right, small-tip approximation).
  • Panel 4: the numbers: BW = TBW/T, Δz = BW/(γ̄Gz), zc = Δfc/(γ̄Gz).
Try this
  • Double Gz (10 → 20 mT/m): the line gets steeper and Δz halves.
  • Halve the pulse (2 → 1 ms): BW doubles → the slice is twice as thick.
  • Change Δfc: the slice moves but keeps its thickness.
  • TBW 2 vs 8: few lobes give rounded slice edges; more lobes give a sharper, more rectangular profile.
Key points
  • Spins are tipped only where their Larmor frequency matches the RF (resonance).
  • Thinner slice: stronger Gz or narrower BW (longer pulse). Moving the slice = shifting the RF frequency.
  • Slice profile ≈ Fourier transform of the RF envelope: sinc pulse → rectangular slab.
Common misconception

"The rephaser lobe is optional." During the pulse, Gz also spreads phase across the slice thickness. The negative lobe (about half the area) rewinds it; without it the slice's own signal would cancel.

\(FOV = \dfrac{BW}{\bar{\gamma}\, G_x}, \quad \Delta x = \dfrac{FOV}{N}\)
What you're seeing (panel guide)
  • Panel 1 (top-left): tissue tubes along x. The coloured strip is the spin phase at the current readout time; each clock is one tube's net signal (thin hand = phase at its centre), spinning at its own pitch f = γ̄Gxx.
  • Panel 2: Gx dephaser + readout; the ticks are the ADC samples, spaced Δt = 1/BW.
  • Panel 3: top = received signal (thin = each tube, white = total, dots = samples). Bottom = FFT of the samples = profile along x (bars), dashed = true object.
  • Panel 4: the tubes' arrows added head-to-tail = the signal the coil receives at this moment.
Try this
  • Play the readout: at the echo (t = 0) all clocks line up → the biggest signal.
  • Raise N (longer readout, more k coverage) → finer Δx and sharper edges.
  • Choose Object wider than FOV: tubes outside the dashed FOV reappear on the opposite side (aliasing). Raise BW or lower Gx to widen the FOV.
  • Noise on + Lock FOV, then lower BW: the noise floor drops (SNR ∝ 1/√BW) but Tacq gets longer.
  • Noise on without Lock FOV: lowering BW shrinks FOV and Δx, so the smaller voxels get noisier.
Key points
  • Frequency encodes position: f = γ̄·Gx·x; the FFT turns frequencies back into positions.
  • FOV = BW/(γ̄Gx) is set by the sampling rate and Gx; Δx = FOV/N by the readout's total k coverage.
  • Noise per sample ∝ √BW, so at fixed voxel size SNR ∝ 1/√BW ∝ √Tacq.

What is held fixed: without Lock FOV, Gx stays fixed (BW changes the FOV). With Lock FOV, Gx is rescaled with BW as a scanner does, so FOV and Δx stay fixed.

Common misconception

"More bandwidth gives more resolution." No: N and FOV set Δx. A wider BW mainly shortens the readout — less time to average noise (lower SNR), but smaller chemical-shift/off-resonance shifts.
